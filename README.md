# Skills-Up-Asesorias-Movil

## Ficha Técnica del Entorno

* *IDE:* Android Studio Ladybug | 2024.2.1 (o versión equivalente)
* *SDK Mínimo:* Android 8.0 (API Level 26)
* *SDK Objetivo:* Android 14 (API Level 34)
* *Lenguaje:* Kotlin 2.0.0
* *Gestor de Dependencias:* Gradle (Kotlin DSL - build.gradle.kts)

## Estructura del Proyecto
El proyecto sigue una arquitectura en capas (Data, Domain, Presentation) para garantizar la separación de responsabilidades.
